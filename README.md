# 🎥 Motion Detector

A real-time motion detection web app built with **OpenCV** and **Streamlit**.

## Features
- Live webcam feed
- Adjustable sensitivity, blur, and minimum area
- Bounding boxes drawn around motion regions
- Optional motion mask view

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
- Python
- OpenCV
- Streamlit
